# Proyecto Bugie

Plataforma de transporte seguro en Trujillo, Perú. Objetivo actual: MVP.

## Stack
- Backend: .NET 8 + Entity Framework Core (Onion Architecture)
- Frontend web: React / Next.js
- App móvil: Flutter
- Base de datos: PostgreSQL

## Estructura de carpetas
- Backend: carpeta Backend
- Frontend: carpeta Frontend

## Cómo compilar
- Backend: entrar a la carpeta Backend y ejecutar dotnet build
- Frontend: entrar a la carpeta Frontend y ejecutar npm install y luego npm run build

## Reglas
- Código simple y limpio, fácil de entender
- Antes de modificar archivos, explícame qué vas a cambiar
- No inventes: si algo no está en el código o en la documentación, dímelo
- Al compilar, muéstrame solo los errores, no toda la salida
- El sistema de puntos (Player Tracking) es Fase 2, NO forma parte del MVP
